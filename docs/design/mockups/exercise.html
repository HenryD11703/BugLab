The Haunted List

The function append_to should take an element and an optional list, append the element to it, and return the result.

When called without a second argument, it should always start fresh with an empty list.

But something strange is happening: it seems to remember values between calls. How?

The bug you found

mutable-default-argument

A default value is evaluated once, when def runs, not on every call. to=[] creates a single list that all calls share, so it keeps growing. Use None as the default and create the list inside the function.

Never use a list, dict or set as a default argument value.
